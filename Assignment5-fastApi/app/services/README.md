# Business Logic Layer (Services)

ส่วนนี้ทำหน้าที่เป็น **Business Logic Layer** หรือส่วนประมวลผลตรรกะทางธุรกิจหลักของโปรเจกต์

## หน้าที่หลัก
- รวบรวมกฎการทำงานของระบบ (Business Rules) ไม่ผูกติดกับ HTTP Framework
- ตรวจสอบความซ้ำซ้อนของข้อมูล (เช่น ตรวจสอบ username ซ้ำก่อนสมัครสมาชิก)
- ดำเนินการ Hash รหัสผ่าน และการยืนยันตัวตน (Authentication)
- เรียกใช้ `UserRepository` เพื่อดึงและบันทึกข้อมูลเข้าฐานข้อมูล

## ไฟล์ในไดเรกทอรีนี้
- `auth_service.py`: บริการจัดการการสมัครสมาชิก (Register) และการเข้าสู่ระบบ (Login)
