# Data Layer (Database Connection)

ส่วนนี้ทำหน้าที่เก็บระบบเชื่อมต่อและจัดเก็บข้อมูลของแอปพลิเคชัน

## หน้าที่หลัก
- จัดการการเชื่อมต่อฐานข้อมูล (Database Engine / In-Memory Storage)
- เตรียม Session หรือโครงสร้างตารางสำหรับการจัดเก็บข้อมูล

## ไฟล์ในไดเรกทอรีนี้
- `database.py`: จัดเก็บโครงสร้างฐานข้อมูลจำลอง (In-Memory Database) สำหรับทดสอบระบบ
